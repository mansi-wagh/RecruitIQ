# RecruitIQ Technical Guide: React (Interview Evidence)

## Purpose
Define interview evidence expectations for React competency. This guide helps interviewers evaluate UI architecture, state management, performance, testing, and accessibility.

## Scope
Applies to:

- Frontend roles using React
- Panels evaluating user-facing application engineering

## Main Content
### 1. Core React competencies
Assess:

- Component architecture:
  - composition and separation of concerns
- State management:
  - local state vs derived state
  - global state patterns when needed
- Performance fundamentals:
  - avoiding unnecessary re-renders
  - memoization and rendering strategy reasoning
- Testing discipline:
  - unit testing and integration/e2e testing awareness
- Accessibility:
  - semantic markup
  - keyboard navigation and screen-reader considerations

### 2. Evidence-seeking question patterns
- “Describe a component you designed. How did you structure props/state and avoid complexity?”
- “How do you prevent unnecessary re-renders in a complex UI? What evidence supports your choice?”
- “Explain how you test a user flow end-to-end.”

### 3. Strong evidence indicators
- Candidate ties UI decisions to user outcomes.
- Candidate can explain trade-offs (simplicity vs flexibility).
- Candidate mentions testing and how they validated correctness.
- Candidate demonstrates accessibility reasoning with practical examples.

### 4. AI decision-support boundaries
RecruitIQ may identify missing skills and suggest interview questions.

- Allowed: select questions aligned to missing competencies
- Required: interviewer validates evidence during the live conversation

Human override:

- override AI-suggested gaps when candidate demonstrates equivalent experience through specific stories.

## Best Practices
- Use debugging scenarios (“What would you inspect if …?”).
- Ask for metrics (“What was improved?”).

## Examples
### Example: Accessibility evidence
- Candidate explains focus management, ARIA usage, and keyboard-driven testing methodology.

## Summary
This React guide defines evidence-based competency evaluation. RecruitIQ AI helps target questions, while interviewers score candidates using rubric-aligned, explainable evidence.
