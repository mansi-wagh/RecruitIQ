# RecruitIQ Technical Guide: Java (Interview Evidence)

## Purpose
Help interviewers evaluate Java proficiency using evidence-based criteria. The guide emphasizes practical reasoning, code quality, and reliability engineering behaviors.

## Scope
Applies to:

- Backend roles using Java
- Interview panels assessing Java language fundamentals, API/service development, and reliability practices

## Main Content
### 1. Core Java competencies
Interviewers should assess:

- Language fundamentals:
  - types, generics, collections
  - exception handling and error propagation
- Concurrency awareness:
  - thread safety basics and safe shared state
- Code structure:
  - separation of concerns
  - clean design for maintainability
- API/service development:
  - validation boundaries
  - logging strategy
- Testing and correctness:
  - unit/integration testing approach
- Performance and memory reasoning:
  - trade-offs in algorithms and resource usage

### 2. Evidence-seeking question patterns
- “Describe a Java service you built. How did you structure modules and responsibilities?”
- “How do you handle error cases in an API? Provide an example with tests.”
- “Explain a concurrency or performance issue you debugged. What was your approach to validation?”

### 3. Code quality signals
Look for:

- readable design with explicit interfaces
- robust exception strategy (no swallowing errors without action)
- test coverage for edge cases
- thoughtful trade-offs (complexity vs maintainability)

### 4. AI decision-support usage
RecruitIQ may generate questions based on skill gaps.

Allowed use:

- select questions aligned to Java competencies
- use follow-ups to elicit evidence

Human override:

- if AI suggests a gap, confirm via interview evidence before deciding on proficiency

### 5. Common pitfalls
- focusing only on syntax or tooling
- inability to explain correctness validation
- vague answers without examples of trade-offs or outcomes

## Best Practices
- Evaluate with scenario-based prompts.
- Require discussion of verification steps (tests, instrumentation, metrics).

## Examples
### Example: Generics understanding
- Candidate explains how they modeled data with generics to avoid casting and to keep interfaces safe.

## Summary
This Java guide provides competency categories, evidence questions, and decision-support boundaries. RecruitIQ AI supports prep and targeting, while interviewers validate capability through human-led rubric scoring.
