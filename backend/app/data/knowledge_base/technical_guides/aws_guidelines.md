# RecruitIQ Technical Guide: AWS (Interview Evidence)

## Purpose
Provide interview evidence expectations for AWS competency. The guide focuses on architectural reasoning, operational awareness, and security-minded patterns—without requiring proprietary service-specific memorization.

## Scope
Applies to:

- Cloud engineer and platform roles
- Panels assessing design, reliability, and operational best practices in AWS

## Main Content
### 1. Core AWS competencies
Assess:

- Architectural reasoning:
  - service selection and why it fits requirements
- Scalability concepts:
  - handling traffic variability
- Reliability principles:
  - availability, failure modes, and resilience
- Cost awareness:
  - cost drivers and cost-control trade-offs
- Security awareness:
  - least privilege concepts and safe configuration practices
- Operational troubleshooting:
  - logging, monitoring, and validation approach

### 2. Evidence-seeking question patterns
- “Design a cloud system for a use case. What services would you choose and why?”
- “Explain how you would troubleshoot a service outage. What would you check first?”
- “How do you control costs without hurting reliability?”

### 3. Strong evidence indicators
- Candidate describes trade-offs and failure mode thinking.
- Candidate includes operational validation steps (metrics, logs, tests).
- Candidate can explain how security principles were applied.

### 4. AI decision-support boundaries
RecruitIQ AI may suggest AWS topics based on missing skills.

Allowed:

- choose question prompts aligned to AWS architecture competencies

Not allowed:

- treating AI-generated confidence as proof

Override:

- if candidate demonstrates equivalent cloud reasoning and operational outcomes, credit the competency even if exact service names differ.

## Best Practices
- Probe for reasoning and validation, not memorization.
- Ask how they measured improvements (latency, cost, error rate).

## Examples
### Example: Cost control
- Candidate discusses selecting right instance types, monitoring usage, and setting alerts to prevent over-provisioning.

## Summary
This AWS guide defines evidence-based evaluation criteria for architectural reasoning, reliability, cost awareness, security concepts, and troubleshooting. RecruitIQ AI assists question targeting, while interviewers validate competence through human-led scoring.
