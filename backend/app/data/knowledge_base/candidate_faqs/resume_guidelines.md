# RecruitIQ Candidate FAQ: Resume Guidelines

## Purpose
Help candidates create resumes that work well with RecruitIQ parsing and recruiter evaluation. The goal is to improve evidence clarity so AI decision-support and human reviewers can assess fit accurately.

## Scope
Applies to:

- Resume/CV submissions for all roles

## Main Content
### 1. What information should I include?
A strong resume includes:

- role titles and time ranges
- skills and technologies you used (with context)
- project summaries with scope and outcomes
- measurable impact (latency improved, users served, cost reduced)
- relevant education and certifications (if applicable)

### 2. How does RecruitIQ parse resumes?
RecruitIQ extracts structured signals such as:

- skill keywords and competency themes
- experience duration and roles
- project descriptions and evidence phrases

AI does not “guess” your capabilities beyond the text and submitted artifacts.

### 3. How should I format my resume?
Recommended formatting:

- clear headings (Experience, Projects, Skills)
- bullet points for achievements
- consistent naming for technologies (e.g., “TypeScript”, not mixed abbreviations)

Avoid:

- images-only text
- unclear bullet points without outcomes

### 4. How do skill gaps get used?
RecruitIQ may detect missing skills relative to role expectations.

- Missing skills may become interview topics
- The purpose is to validate competence and explore equivalent experience

### 5. How should I handle employment gaps or role changes?
Be transparent and concise:

- summarize what you did during gaps (projects, learning, responsibilities)
- clarify how skills transferred to the target role

### 6. What about multiple versions of my resume?
If updates are allowed:

- submit the most accurate version
- include any newly completed projects or achievements

RecruitIQ will re-run parsing and update internal decision-support inputs.

### 7. Can I include portfolio links?
Yes. Portfolio links help recruiters verify evidence.

- Include links to code repos, case studies, or dashboards when allowed.

## Best Practices
- Prefer evidence-backed bullets: “Implemented X resulting in Y.”
- Match resume scope to the role’s competency model.

## Examples
### Example bullet (good)
- “Built a REST API with pagination and caching; reduced response time by 35% and improved reliability with integration tests.”

### Example bullet (weak)
- “Worked on backend features.”

## Summary
RecruitIQ resume guidelines emphasize clarity, evidence, and consistent formatting. AI parsing uses submitted text, and skill-gap findings are used to guide recruiter probing—not to automatically reject candidates.
