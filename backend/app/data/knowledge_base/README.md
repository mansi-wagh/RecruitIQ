# RecruitIQ Knowledge Base (RAG)

This folder contains enterprise recruitment and AI decision-support documentation for **RecruitIQ**, intended for retrieval-augmented generation (RAG).

## Ingestion expectations

The backend RAG pipeline loads files with extensions:

- `.md`
- `.txt`

Files are chunked automatically and embedded for semantic retrieval.

## Document organization

Policies, interview guides, candidate FAQs, company docs, recruiter guidance, and technical guides are separated by subfolders to improve relevance during retrieval.
