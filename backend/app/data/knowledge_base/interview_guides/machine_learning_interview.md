# RecruitIQ Machine Learning Interview Guide

## Purpose
Offer a structured interview guide for machine learning roles that evaluates modeling fundamentals, training/evaluation processes, and responsible ML behaviors. RecruitIQ AI supports question preparation but never replaces human rubric scoring.

## Scope
Applies to:

- machine learning engineers and applied ML roles
- technical panels focused on model development and evaluation

## Main Content
### 1. Competencies
Key competencies:

- supervised/unsupervised learning fundamentals
- feature representation and data preparation
- training workflow and hyperparameter rationale
- evaluation metrics and error analysis
- interpretability and responsible ML practices

### 2. Recommended interview flow
- fundamentals check: translating concepts into practical choices
- modeling scenario: building/adjusting a pipeline with constraints
- evaluation deep dive: metrics, validation, and failure modes
- responsible ML: bias/robustness and monitoring concepts

### 3. AI-assisted question generation
RecruitIQ may suggest questions for missing skills.

Interviewers must ensure:

- questions map to rubric competencies
- questions elicit reasoning and trade-offs

Probe further when:

- RecruitIQ confidence signals are low
- the candidate gives generic definitions without evidence of implementation experience

### 4. Question frameworks
Training rationale:

- “Why did you choose that objective function and model family?”

Hyperparameters:

- “How did you search hyperparameters and prevent overfitting?”

Evaluation and failure modes:

- “Describe a failure mode you discovered. How did you detect it and mitigate it?”

Interpretability:

- “What techniques do you use to interpret predictions, and what are the limitations?”

Responsible ML:

- “How do you detect bias or unfair outcomes in your modeling process?”

### 5. Scoring rubric anchors
Strong candidates articulate training/evaluation choices with correctness and demonstrate error analysis beyond average metrics. They explain limitations honestly and propose monitoring strategies.

### 6. AI confidence and override
Treat RecruitIQ signals as hypotheses.

Override when:

- the candidate demonstrates deeper understanding than resume implies
- AI maps a missing skill incorrectly

### 7. Best practices
- Use consistent scenarios for comparable assessment.
- Require specific examples with measurable outcomes.

## Examples
### Example: Overfitting hidden by metrics
The candidate explains validation strategy and additional robustness checks (e.g., error analysis by segments, out-of-distribution awareness).

## Summary
This ML interview guide standardizes competency-based assessment and enforces evidence-based scoring with explicit responsible ML expectations. RecruitIQ AI is preparation support only.
