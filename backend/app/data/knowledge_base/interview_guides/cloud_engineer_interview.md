# RecruitIQ Cloud Engineer Interview Guide

## Purpose
Define a cloud engineering interview guide that assesses proficiency in cloud architecture, scalability, networking concepts, and operational readiness.

## Scope
Applies to:

- cloud engineer roles
- panels evaluating design reasoning, reliability, and operational security

## Main Content
### 1. Competency areas
Common competencies:

- cloud architecture and service selection
- networking basics (VPC, routing concepts)
- scalability and performance considerations
- security and access control concepts
- cost awareness and optimization thinking

### 2. Interview structure
Recommended sections:

- architecture scenario
- networking and failure modes
- scalability and performance trade-offs
- security and operational practices
- cost reasoning and validation

### 3. AI-supported preparation
RecruitIQ may suggest questions for missing skills.

Interviewers should choose questions that map to rubric competencies and probe with follow-ups.

### 4. Question frameworks
- architecture:
  - “Design an application on the cloud. What services and why?”
- networking:
  - “Explain how traffic flows from client to service and what can fail.”
- scalability:
  - “How do you handle burst traffic and autoscaling? What metrics guide scaling?”
- security:
  - “Describe least privilege access and secure network segmentation concepts.”
- cost:
  - “What levers do you use to control costs without hurting reliability?”

### 5. Scoring guidance
Strong candidates demonstrate correct service selection reasoning, practical failure-mode awareness, security-minded choices, and a clear cost/reliability balance.

### 6. Human override triggers
Override AI interpretation when:

- candidate shows relevant cloud experience not captured in resume
- AI identifies incorrect gaps for the real competency

## Best Practices
- Use design constraints to differentiate experience.
- Ask for reasoning and validation steps.

## Examples
### Example: burst traffic scenario
Follow-up probes:

- “How do you validate autoscaling meets reliability targets?”
- “How would you prevent thundering herd effects?”

## Summary
This cloud engineer guide standardizes competency evaluation and ensures AI suggestions are used only for preparation and decision support with human-led scoring.
